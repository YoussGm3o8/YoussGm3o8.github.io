# Youssef El Kesti — Portfolio

Source for [youssefelkesti.ca](https://youssefelkesti.ca/).

A dependency-free static portfolio focused on embedded systems, avionics, robotics, and selected software projects. The site is intentionally plain HTML/CSS/JavaScript so content updates do not require rebuilding a framework-generated bundle.

## Structure

- `index.html` — portfolio content and metadata
- `styles.css` — responsive visual system
- `script.js` — navigation, reveal effects, dynamic footer year
- `404.html` — custom not-found page
- `favicon.svg` — site icon
- `CNAME` — custom domain configuration

## Updating

Edit the files directly on the `dev` branch, validate locally with any static HTTP server, then publish the same static files to `gh-pages`.
